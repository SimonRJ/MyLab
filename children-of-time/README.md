# Children of Time Universe Atlas — Books I–III only

A free, unofficial, illustrated interactive atlas for the first three novels by Adrian Tchaikovsky. All details after *Children of Memory* are excluded.

## Use on an iPhone

**Do not tap the GitHub HTML file's Raw link or a ChatGPT .html attachment and expect the app to run.** Safari and iPhone Quick Look often present raw code or block JavaScript.

### Open immediately (third-party preview)

https://raw.githack.com/SimonRJ/MyLab/main/children-of-time/index.html

This uses raw.githack.com's HTTPS proxy; it may ask you to confirm once before opening the page.

### Turn on GitHub Pages for a permanent link

1. Open https://github.com/SimonRJ/MyLab/settings/pages
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose **main**, **/(root)** and **Save**.
4. Once GitHub Pages confirms the site is published, the atlas URL will be:
   https://simonrj.github.io/MyLab/children-of-time/

The atlas is a **single self-contained HTML file** (all images, style and JavaScript included), requires no account and sends no analytics.

## Scope

65 character dossiers, 72 timeline entries, 8 worlds, 16 ships and craft, 23 locations, 12 routes, author commentary and a first-three-book refresher. Full spoilers for Books I–III. No information from later books.

Original fan artwork and schematic maps are interpretive, not official canon.
